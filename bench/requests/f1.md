Feature: invoice payments for ledger-lite.

Staff record payments against an invoice.

1. `recordPayment(invoiceId, amount)` in `src/invoices.js`. `amount` is a baht string such as "100.50". It returns the updated invoice.
2. An invoice keeps `payments` (an array of satang amounts, oldest first) and `paidSatang` (their sum). Its `status` is OPEN with no payment, PARTIAL while paid is below the total, and PAID when paid equals the total.
3. Errors, by `err.code`: NOT_FOUND for an unknown invoice; BAD_AMOUNT when the amount is not a valid positive baht string ("0.00" is not valid); OVERPAYMENT when the payment would take paid above the total. A rejected payment changes nothing.
4. Two clerks can open the same invoice at the same time, so one clerk's payment must never overwrite another's. `store.save(record, expectedVersion)` must throw STALE_VERSION when the stored record's version is not `expectedVersion`. Every stored record carries an integer `version` that is 1 on its first save and goes up by 1 on each save. Saving an existing record without `expectedVersion` is STALE_VERSION. `recordPayment` must save with the version it read.
